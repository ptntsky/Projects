# Лабораторна робота № 4

Файли в архіві:
- `index.html` та `css/style.css` — адаптивна головна сторінка, модальне вікно `Sign in` (`:target`), адаптивне меню, плавний перехід вгору, карусель відгуків і валідація форми виключно засобами HTML5 та CSS (`required`, `pattern`, `:valid`, `:invalid`, `:not(:placeholder-shown)`).
- `bootstrap-page.html` — сторінка з використанням Bootstrap 5.
- `scss/sass-page.scss` та `css/sass-page.css` — вихідний код Sass/SCSS та скомпільований CSS.
- `invitation.html` — запрошення та конверт із кнопкою друку та стилями `@media print`.
